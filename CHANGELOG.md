# Changelog — ARVID Visual Interface

## v0.2.1 — 2026-07-08 — фикс «пустых» маркеров, чистка топбара

### Исправлено

- **Пустые неубираемые иконки на плане комнаты.** Причина: на плане (обычный режим)
  маркеры рисовались для ВСЕХ сущностей помещения (`getRoomEntities`), включая старые
  записи layout вне скоупа (климат/шторы/сцены) — им общий стор `web_interface.layout`
  проставил координаты, а иконок для них уже нет → рисовался пустой кружок. В режиме
  редактирования список берётся из скоупа, поэтому такие устройства нельзя было выбрать
  и «убрать с плана». Фикс: единый фильтр скоупа `getScopedEntities()` и для плана, и для
  редактора — вне-скоупные устройства не рисуются вообще (`getEditableEntities` → `getScopedEntities`).

### Удалено

- Кнопка «Автоматизации» в топбаре главной (была статичной заглушкой без обработчика).

> Первопричину — общий замусоренный layout-стор со старым интерфейсом — закрывает
> переход на собственный backend (в работе, см. CLAUDE.md «Дальнейший путь»).

## v0.2.0 — 2026-07-07 — редактирование внутри помещения, единые иконки

Правки контракта (DESIGN.md, решение 20): редактор — НЕ отдельная страница, а режим
редактирования внутри помещения; функциональность упрощена до списка устройств с фильтрами.

### Изменено

- **Режим редактирования в комнате** (`room-page.js`): кнопка «Редактор» в шапке комнаты
  включает режим (кнопка становится «Готово»). Вместо панелей управления показывается
  карточка «Расстановка устройств»: фильтры (Все/Свет/Датчики/Панели), список устройств
  помещения (иконка + имя + entity_id + статус «на плане/не размещено»), подсказка,
  действия «В центр плана»/«Убрать с плана», «Сохранить разметку», строка статуса.
- **Перенос маркеров**: drag на компьютере, тап по плану на телефоне (механика прежнего
  редактора перенесена в комнату). Убранные с плана устройства в режиме редактирования
  видны полупрозрачными, выбранное устройство подсвечено рамкой.
- **Несохранённые изменения**: при выходе из режима — подтверждение
  (сохранить / отменить с перечиткой layout из HA).
- **Иконки в едином стиле** (панель-градиент + гравировка, viewBox 120): починен
  `light.svg` (у экспорта Illustrator был viewBox 14400 — иконка рендерилась пустой),
  добавлены `illuminance.svg` (солнце) и `panel.svg` (панель с ручкой и кнопками).
  Настройки формы/иконки маркера удалены — иконка назначается автоматически по типу.
- Заголовки вкладки: «ARVID Visual Interface» / «— Помещение».

### Удалено

- Страница редактора целиком: `editor-page.js`, `editor.css`, editor-view в `index.html`,
  кнопки «Редактор» в левой панели этажа, маршрут `view=editor` (fallback на floor),
  анимации переходов to-editor/from-editor, ссылки `#editorLeftPanel` в shell-ui,
  выбор типа маркера (круг/квадрат) и ручной выбор иконки.

### Версии

- Frontend: `v0.2.0`; backend не менялся.

## v0.1.0 — 2026-07-07 — форк web_interface, чистка под скоуп «свет»

Новый проект: форк `web_interface` v0.9.2 с сохранением мобильной вёрстки и SPA-архитектуры.
Скоуп зафиксирован в DESIGN.md: свет · движение/освещённость · кнопочные/поворотные панели.

### Перенесено из базы (без изменений)

- SPA: `index.html` (floor/room/editor), spa-router, View Transitions, ARVID_APP/ARVID_RUNTIME
- Вёрстка: shell/floor/room/editor/schedule CSS, мобильные аккордеоны, Quick View, popup расписания
- Backend `custom_components/web_interface` (хранилище layout, домен оставлен прежним —
  общий layout со старым интерфейсом, без перенастройки HA)
- Правила деплоя (DEPLOY.md, пути обновлены на `visual_interface`)
- Скиллы из `.claude copy` → `.claude/skills`
- Спека API ядра `WEB_INTERFACE_API.md` и контракт `DESIGN.md` (из arvid-web-interface)

### Удалено (вне скоупа)

- **Климат**: карточка климата в комнате, климат в Quick View и сводке этажа,
  `climate.*` из типов устройств, попап управления климатом, CSS `.climate-*`
- **Шторы**: карточка штор, `cover.*` из типов, иконка cover.svg
- **Датчики температуры/влажности/CO₂**: детекторы в device-ui, метрики Quick View,
  пороговые предупреждения этажа (temperature/humidity/co2), иконка temperature.svg
- **Сценарии**: карточка «Быстрые сценарии», `scene.*`/`script.*` из типов, CSS `.scenario-*`
- Иконки climate/cover/temperature/fan, устаревшие `room.html`/`editor.html`,
  локальные бэкапы `assets/Версия claude/`, неиспользуемый `supportsPopupControl`

### Добавлено (закладка нового скоупа)

- `device-ui.js`: `isPanelEvent()` + `panelEventText()` — панели как `event.*`
  (click/double/hold/hold_end/rotate + key_no), тип маркера `panel`
- Комната: read-only карточка «Панели» (последнее событие по каждой панели),
  попап панели по клику/долгому тапу на маркер
- Quick View: метрика «Освещённость» (lx) вместо климата/CO₂/влажности
- Сводка этажа: карточка «Движение» (помещения с активным движением, переход в комнату)
- Слот «Предупреждения» сохранён с заглушкой — наполнение сигналами скоупа спроектируем отдельно
- Редактор: типы устройств ограничены `light./sensor./event.`, иконка «Панель»
- CSS: цвет маркера `device-kind-panel` (комната + редактор)

### Версии

- Frontend: `v0.1.0` (`js/config.js`), новый отсчёт
- Backend: не менялся, остаётся на версии базы (0.9.x)
